# ServerPing

A Darktide Mod Framework utility for measuring matchmaking-region latency from the Mourningstar, comparing endpoints, viewing recent and accumulated results, and selecting a preferred region for the current session.

## Installation

Install DMF, place the `ServerPing` folder in Darktide's mods directory, and add `ServerPing` to `mod_load_order.txt`.

## Download

Download `ServerPing.zip` from the [latest GitHub release](../../releases/latest). Do not use GitHub's source-code archives for installation.
